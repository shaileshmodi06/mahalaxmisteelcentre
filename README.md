# Mahalaxmi Steel Centre website

Run locally in VS Code:
1. Extract this ZIP and open the project folder.
2. Run `npm install`
3. Run `npm run dev`
4. Open the localhost URL Vite prints (normally http://localhost:5173).

Before publishing, edit `src/config.js` and add the confirmed shop phone and WhatsApp number. `whatsapp` must contain digits only with country code, for example `919876543210`. Confirm the complete address and replace the Maps search URL with the exact share link if available.

Replace image files in `public/`:
- `logo.png` — replace the temporary logo with the supplied original logo.
- `shop-front.jpg` — actual shop front.
- `shop-interior.jpg` — actual interior.
- `owner.jpg` — owner's portrait.

The website includes a fade-transition hero slideshow, metallic industrial theme, product category cards, owner photo area, gallery/lightbox, map directions, contact panel and floating WhatsApp shortcut. Product categories are examples; verify actual inventory before publishing. Confirm full address, phone and opening hours with the owner.
